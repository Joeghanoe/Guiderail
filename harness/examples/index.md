* [E-011 A health endpoint is its own class, and the client decides what its response means](e-011-one-class-one-job.md) - The health function does not share a class with business functions, and the service class answers "is it healthy" itself instead of passing the raw response out. * [E-012 A gateway policy does not repeat what the gateway already enforces](e-012-use-what-the-platform-does.md) - An API that requires a subscription key does not also check the key in every operation policy; request shapes are validated once at the front with the platform's validation. * [E-013 A pipeline step calls a script; it does not contain one](e-013-pipelines-call-scripts.md) - A long inline PowerShell block is untestable and unmaintainable; the logic lives in a script file the step calls with parameters. (violation, human-reviewed)
* [E-014 Unhealthy is not a 200, and health covers the queues and credentials the service uses](e-014-health-reports-unhealthy.md) - A health endpoint returns a failing status code when a dependency or credential is bad, and checks every dependency instead of only the API.
