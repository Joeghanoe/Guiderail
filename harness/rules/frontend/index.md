# Rules

* [UI.1 A visual change is looked at, at every screen size, before it is called done](ui-1-look-at-what-you-built.md) - A change to something users see is rendered, screenshotted at phone, tablet and desktop widths, checked for WCAG 2.2 AA, and judged against the people who will use it.
* [UI.2 A screen shows what the user can do, not what the screen is for](ui-2-show-what-users-can-do.md) - Every element on a screen helps the user reach their goal. Text that explains the product, the screen or the spec is removed; headers, footers and cards carry only what the user acts on.
