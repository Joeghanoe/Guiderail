# Rules

* [H.1 Feedback becomes an example; principles change only by a human decision](h-1-feedback-becomes-an-example.md) - A correction of output that came from the harness is recorded as a proposed example, not as an edited rule.
* [H.2 Repeated work moves up the automation ladder](h-2-repeated-work-moves-up.md) - A task done a second time becomes a playbook; a playbook that is mostly commands becomes a script; a script that guards a rule becomes a hook or CI check.
