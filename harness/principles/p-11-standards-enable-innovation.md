# P11 Standards Enable Innovation

Standards remove needless variation so effort goes to new problems.

Vegviser is the authority for this principle; this file only points to it.[^vegviser] Read the source when a
finding depends on the exact wording. A deviation follows Vegviser's Exception and Risk Acceptance playbook.

[^vegviser]: Vegviser Principles, P11

# Application to standards and work instructions

A principle gives durable direction; a standard defines an observable expectation and its scope; a work
instruction specifies how to carry it out. All can be mandatory within their approved scope. Keep their
authority, exceptions and evidence explicit rather than promoting a local implementation to a universal
principle. Review inferred repository conventions before making them authoritative.

The supplied Cloud Principles.pdf, p. 13, supports the current stable framework or its immediate
predecessor. DEL.2 already expresses that window. The shorter n-1 wording in the imported global
instructions needs alignment by its owner; it should not silently tighten the existing gate.
