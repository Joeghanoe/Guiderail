# Benchmark navigation

Use these indexes to inspect evaluation scenarios, candidate tasks and acceptance criteria. This navigation is for evaluators; it is separate from the engineering guidance graph.

- [Brownfield validation cases](cases/README.md#validation-case-index) pair change tasks with hidden grading criteria, case configuration and pinned source snapshots.
- [Greenfield scenarios](greenfield/README.md) pair new-service tasks with published acceptance requirements and scenario configuration.
- [Reference project validation](reference-projects.md) explains source registration, freezing and known gaps.

The [case split and execution rules](cases/README.md) govern validation and holdout separation. Keep evaluator navigation outside candidate workspaces. Do not add links from candidate tasks or installed guidance to hidden criteria, and do not turn validation criteria into training guidance.
