# Feedback

Draft examples from every repo land here through `~/.golden-path-harness/feedback/` (H.1).

The [process-feedback playbook](../harness/playbooks/process-feedback.md) owns classification, capture, weekly human review and the local submission command. Follow it when proposing or accepting feedback.

Keep only undecided feedback here. After processing, move the source record to [docs/feedback/processed](../docs/feedback/processed/) and update the [editable decision record](../docs/decisions/feedback-conventions.md). Decisions can change with experience; they do not require an ADR.
